## About me

I build **Python tools and automation frameworks** that make tests easier to develop, run and understand. I have **5+ years of experience** in automated testing and currently work as a **Senior Tester at EPAM Neoris, with AXA**.

My work includes test architecture, web and API automation, execution infrastructure, reporting and technical mentoring. I'm building toward an **SDET role (Software Development Engineer in Test)** through software design and reusable tooling.

## What I do

- **🌐 Web test automation** — Reusable browser flows, page objects and clear assertions.
- **🔌 API testing** — HTTP requests, payloads, business rules and response validation.
- **🧱 Automation architecture** — Separate responsibilities and reusable keywords, components and layers.
- **🗂️ Data-driven testing** — Parametrized scenarios and reusable test data.
- **🛠️ Testing tool development** — Python utilities for data, annotations, console output and evidence.
- **⚙️ CI test execution** — Automated runs and report publication with GitHub Actions.
