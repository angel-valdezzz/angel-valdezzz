# Profile artwork and technology badges

The constellation banner and badge layouts were created for this profile. Technology logos use the original geometry and colors already used in [the portfolio](https://github.com/angel-valdezzz/angel-valdezzz.github.io/tree/main/public/assets/technologies). The Xray PNG is embedded unchanged. Some logos have a light or dark backing for contrast. SQL uses an original generic database glyph, without a database vendor.

Both README languages share local dark and light artwork. Each technology name also appears in the expandable, text-based descriptions. No remote statistics or badge-generation service is required.
